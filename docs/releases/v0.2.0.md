# v0.2.0

- 「通常回線で開く（ログイン用）」と「VPNで開く」を分離。起動済みのゲーム・更新ツールは二重起動しません。
- 通常回線で開く操作ではManagerのVPNだけを切断し、VMの起動・停止は行いません。
- 設定ファイル、鍵の形式、VPNクライアント、管理者権限、認証ファイル、クラウド読み取りの診断を追加。診断操作は接続やVMの起動・停止を行いません。
- 診断コピーと直近80件の操作履歴を追加。コピー時は認証情報・鍵・IP・個人パス・プロジェクト名等を除去します。共有前に内容をご確認ください。
- ファイル選択、自動検出、基本／詳細設定を追加。接続設定の変更はVPN切断後に行います。
- ゲーム終了から15秒の猶予を設けて自動切断。更新ツールへの引き継ぎを監視し、自動切断を設定から無効化できます。VM停止は別操作です。
- Managerの二重起動を防止。ゲーム起動中・VPN接続中の更新適用をブロックし、アプリ終了時の自動更新適用を停止。
- Terraformの計画は設定保存時に無効化し、変更後の再確認を必要にしました。

設定・WireGuard鍵の移行は不要です。プレイ終了後にManagerを終了して新しい版を開いてください。

検証: 単体テスト38件、型チェック、Windowsでの製品ビルドとプリロード起動検査。新UIの実画面操作と新しい起動フローの実接続は未検証です。実行中のゲーム・VPN・VMは変更していません。ゲームへの接続先切り替え効果はゲーム側の再接続タイミングにも依存します。
