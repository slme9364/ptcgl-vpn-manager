# v0.1.9

## 再接続の修正

- 接続先IPが前回と同じときに「WireGuard config has no Endpoint entry」と誤判定する問題を修正。
- クライアントのトンネルIPが変わらない場合も、そのまま受け付けるよう修正。
- 設定ファイルの権限を、PowerShellの追加モジュール読み込みに依存せず適用。

## WindowsのPTCGL専用VPN

- WireSock Secure Connect CLI 3.8の配置先に対応。
- `AllowedApps` を公式仕様の `[Peer]` セクションへ配置し、設定したPTCGL実行ファイルだけを対象にする。
- アプリ単位モードではDNSの上書きを外し、他アプリの通常回線を維持。
- WireSockもサーバーのハンドシェイク応答を確認してから接続済みと表示。
- ドライバーの利用失敗、起動直後の終了、実行中の終了を検出。
- クライアントを切り替えるときは旧トンネルを終了し、同時接続を防止。
- 画面に「PTCGL専用」を表示。WireSockによる接続はManager終了時に切断。

WireSock CLIは別途インストールが必要です。`winget install --id NTKERNEL.WireSockVPNClientCLI --exact --source winget` を使えます。個人利用でのライセンス条件は公式サイトを確認してください。Windowsのパケットフィルターを扱うため、Managerは管理者として起動します。

PTCGL専用モードではChrome等の出口IPが通常回線のままになることが正常です。PTCGLのアカウントログインや対戦動作は、ユーザー側での確認が必要です。
