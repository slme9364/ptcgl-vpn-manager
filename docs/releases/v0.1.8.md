# v0.1.8

## 修正

- WindowsのLocalSystemサービスがユーザープロファイル内の設定ファイルを開けずに停止する問題に対応。サービス用の設定をProgramDataへ配置し、秘密鍵を書き込む前に所有ユーザー・SYSTEM・Administratorsだけに権限を限定します。


- Windowsで起動画面が真っ黒になる問題を修正。sandbox対応のCommonJS preloadを生成・読み込み、ビルド時にも起動用IPCを検査します。
- Windowsで、WireGuardサービスの起動だけで「接続済み」と表示していた判定を修正。今回の接続後のサーバーハンドシェイクを確認し、未確認の場合はエラーとしてトンネルを解除します。
- Windowsで、最終ハンドシェイク時刻・送受信バイト数を表示。接続後も状態を確認し、古い接続表示が残るのを防ぎます。
- 停止済みのWindowsトンネルサービスが残っている場合、接続先を更新してサービスを作り直します。
- クリーンアップで実際のインストール先、更新キャッシュ、バージョン付き登録名を取りこぼす問題を修正。
- VMの外部IPv4と、PCが実際に利用している出口IPを混同しないよう表示名を変更。

## 配布物

Windows x64のNSISインストーラー・ZIP、macOS Apple SiliconのDMG・ZIPを同じタグから生成します。既存v0.1.6のVM自動起動処理も含みます。

コード署名・macOS公証は未実施です。ハンドシェイクはWireGuardサーバーとの通信確認であり、Webサイトの地域判定や各サービスの利用可否を保証するものではありません。

Windowsでの起動修正・単体テスト・ビルドを検証しています。ユーザーがVMを停止した後の実VPN再接続、Chromeの出口IP、PTCGLのダウンロードは未検証です。
